# Rascunhos editoriais

Arquivos nesta pasta existem apenas em branches de revisão.

Antes do merge para `main`, o conteúdo aprovado deve ser movido para `../ensaios/`, receber o status `publicado-no-repositorio` e ser incluído no [índice de artigos](../README.md).

Merge no GitHub não autoriza nem executa publicação no LinkedIn, DEV.to ou Medium.
