# Module 01 — Fundamentals and Workloads

This module introduces the objects that make an application declarative and updatable: Deployment, ReplicaSet, Pod and Service.

## Objectives

- Understand the relationship between Deployment, ReplicaSet and Pod.
- Declare replicas and a RollingUpdate strategy.
- Expose Pods through a ClusterIP Service.
- Follow a rollout and recognize when it isn't progressing.
- Return to a healthy revision with a rollback.
