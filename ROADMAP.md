# Roadmap

The roadmap tracks a learning journey and doesn't represent a guarantee of full CKA exam coverage.

## Phase 1 - Foundation

- Repository structure.
- Essential concepts.
- First lab in the browser.
- Initial glossary.

## Phase 2 - Workloads

- Pods.
- Deployments.
- ConfigMaps and Secrets.
- Scheduling and autoscaling.

## Phase 3 - Cluster administration

- Control plane components.
- kubeadm.
- RBAC.
- Upgrade and lifecycle.
- Helm, Kustomize and extensions.

## Phase 4 - Networking and storage

- Services and discovery.
- Network Policies.
- Ingress and Gateway API.
- CoreDNS.
- PV, PVC and StorageClasses.

## Phase 5 - Troubleshooting

- Pods and workloads.
- Nodes and cluster components.
- Logs and events.
- Services and networking.
- Resource usage.

## Pace

This track is built alongside CKA preparation and university work, one module at a time. Each module ships when its lab has been validated end to end, not against a fixed date — the [status table below](#status) is the current source of truth, not a deadline.
